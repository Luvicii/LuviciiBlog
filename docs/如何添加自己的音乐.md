# 如何在音乐馆添加自己的音乐

音乐馆（`/music/`）支持两种歌单：**平台歌单**（网易云/QQ音乐，走 Meting 接口）和**本地歌单**（自己上传的音频直链）。本文档说明如何添加自己的音乐（原创作品、CC 授权或无版权音乐）。

> 注意：图床仓库和博客都是公开的，请只上传自己制作的或允许公开传播的音乐。商业版权歌曲不要上传，否则可能收到 DMCA 投诉导致图床仓库被封。

## 第 1 步：上传音频文件

使用仓库根目录的 `uploadMusic.sh`（与 `uploadIMG.sh` 同一个图床仓库 `Luvicii/Luvicii-images`，文件存到 `music/` 目录）：

```bash
# 只传音频
./uploadMusic.sh 我的歌.mp3

# 音频 + 封面
./uploadMusic.sh 我的歌.mp3 封面.jpg

# 音频 + 封面 + 歌词
./uploadMusic.sh 我的歌.mp3 封面.jpg 歌词.lrc
```

推送成功后，脚本会打印一段 YAML 配置，形如：

```yaml
      - name: 我的歌
        artist: 歌手名
        url: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/我的歌.mp3
        cover: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/封面.jpg
        lrc: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/歌词.lrc
```

## 第 2 步：写入配置

打开 `_config.luvicii.yml`，找到 `music_playlist`，新增一个本地歌单（填 `songs` 列表，不填 `id`/`server`），把脚本输出的歌曲条目粘贴进去：

```yaml
music_playlist:
  - name: 网易云
    id: 606061417
    server: netease
  - name: Lrxin You
    id: 2183317608
    server: netease
  - name: 我的音乐            # ← 本地歌单
    songs:
      - name: 我的歌
        artist: Lrxin
        url: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/我的歌.mp3
        cover: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/封面.jpg
        lrc: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/歌词.lrc
      - name: 第二首          # ← 更多歌曲继续追加
        artist: Lrxin
        url: https://fastly.jsdelivr.net/gh/Luvicii/Luvicii-images@main/music/第二首.mp3
```

每首歌的字段：

| 字段 | 必填 | 说明 |
| ---- | ---- | ---- |
| `name` | 是 | 歌名 |
| `artist` | 是 | 歌手/作者 |
| `url` | 是 | 音频直链 |
| `cover` | 否 | 封面图直链。**留空时构建阶段会自动按"歌名 + 歌手"从 QQ 音乐匹配专辑封面**，匹配结果缓存到 `source/_data/music_cover_cache.json`（建议提交到 git，后续构建和 CI 部署无需重复查询）；匹配不到会在构建日志里警告 |
| `lrc` | 否 | 歌词文件直链（不填则无歌词） |

## 第 3 步：重新部署

```bash
npm run build     # 或 hexo generate && gulp min
```

部署后进入音乐馆，新歌单会出现在右下角的歌单列表里，随机播放、刷新、循环切换按钮对本地歌单同样有效。改了网易云歌单内容后，点右下角"重新加载当前歌单"按钮即可看到最新曲目。

## 常见问题

- **jsDelivr 单文件上限 20MB**。MP3（3~10MB）没问题；FLAC 经常超限，建议先转成 MP3/M4A：
  ```bash
  ffmpeg -i 输入.flac -b:a 320k 输出.mp3
  ```
- **文件名含中文/空格**：可以直接用，浏览器会自动编码；但建议文件名避免特殊符号（`#`、`?` 等）。
- **jsDelivr 国内偶尔不稳定**：如果播放卡顿，可以把音频迁到 Cloudflare R2（10GB 免费、流量免费），配置里只需替换 URL。
- **不想传图床**：也可以把音频放进 `source/media/music/`，然后 `url` 写 `/media/music/歌曲.mp3`，随站点一起部署（注意会增大博客仓库体积）。
